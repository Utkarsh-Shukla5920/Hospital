# Care-Point

**Your Health, Our Priority.**

Care-Point is a healthcare website project created to bring healthcare information, hospital services, and medical store products together in one place.

I built this project using HTML, CSS, and JavaScript to practise web development and create a simple website that is easy to explore.

## About the Project

The main idea behind Care-Point is to make healthcare-related information easier to find through a single website.

Visitors can explore different healthcare service categories, view medical store products, learn about Care-Point, and use the contact form.

## Features

- **Home Page** – Introduces Care-Point and its purpose.
- **Services Section** – Displays six categories:
  - General Checkup
  - Emergency Care
  - Laboratory Tests
  - Diagnostic Services
  - Child Healthcare
  - Pharmacy / Medical Store
- **Products Section** – Displays medical and healthcare products with sample prices.
- **About Us Section** – Explains the idea and purpose of Care-Point.
- **Contact Section** – Includes contact information and a message form.
- **Footer** – Provides navigation links and copyright information.
- **Mobile Navigation** – Includes a menu for smaller screens.
